## 🎯 ENHANCED PROBLEM STATEMENT

Design a reinforcement learning agent that controls an **Autonomous Mobile Robot (AMR)** in a realistic warehouse with **complex operational requirements**:

### Real-World Constraints Added:

1. **Battery Management System**
   - Robot starts with 100% battery
   - Loses 1% battery per movement action
   - Loses 2% battery when carrying heavy packages
   - Must autonomously return to charging station when battery < 20%
   - Charging takes time (gains 5% per time step at station)
   - **Critical**: Robot cannot complete delivery if battery runs out mid-task

2. **Complex Multi-Stage Tasks**
   - **Inbound Workflow**: Receiving Station → Storage Zone → Inventory Update
   - **Outbound Workflow**: Storage Zone → Packing Station → Shipping Zone
   - **Transfer Tasks**: Storage A → Storage B (reorganization)
   - **Priority Handling**: Urgent packages (30 min deadline) vs Standard (no deadline)

3. **Zone Authorization System**
   - **Allowed Zones**: Storage areas, corridors, shipping zones, charging stations
   - **Restricted Zones**: Office areas, break rooms, quality control labs
   - **Time-Based Restrictions**: Some zones closed during shift changes (steps 100-120, 300-320)
   - **Penalty**: -50 for entering unauthorized zone

4. **Realistic Human Behavior**
   - **Workers on Schedules**:
     - Morning shift (steps 0-200): 4-5 workers in storage/picking zones
     - Lunch break (steps 200-250): 2-3 workers, mostly in break areas
     - Afternoon shift (steps 250-500): 3-4 workers in shipping zones
   - **Free Movement Patterns**:
     - 60% purposeful (moving toward workstations, packages, exits)
     - 25% social (chatting with coworkers, causing unpredictable stops)
     - 15% random walk
   - **Unexpected Events**: Workers suddenly stopping, changing direction, group formations

5. **Multiple Pickup/Delivery Points**
   - **3 Storage Zones**: A (electronics), B (textiles), C (tools)
   - **2 Receiving Stations**: Truck dock, rail dock
   - **2 Packing Stations**: Standard packing, fragile item packing
   - **3 Shipping Zones**: Local delivery, express shipping, international
   - **2 Charging Stations**: Main charging bay, emergency charging point

6. **Package Properties**
   - **Type**: Standard, Fragile, Heavy, Urgent
   - **Source-Destination Pairs**: 15 possible combinations
   - **Weight Effect**: Heavy packages slow robot (50% speed reduction)
   - **Fragile Handling**: Cannot move through high-traffic corridors

7. **Safety-Critical Scenarios**
   - **Forklift Right-of-Way**: Must yield or face -100 penalty
   - **Human Safety Zones**: 1.5m minimum distance (enforced)
   - **Emergency Stops**: Random equipment maintenance blocks corridors
   - **Spill Zones**: Temporary obstacles requiring rerouting

## 🎮 ENHANCED ACTION SPACE

**Discrete(11)**: More realistic control

```python
Actions:
0: Move North
1: Move South  
2: Move East
3: Move West
4: Wait (useful when human blocking path)
5: Pickup Package (only valid at pickup zones)
6: Drop Package (only valid at delivery zones)
7: Start Charging (only valid at charging stations)
8: Stop Charging (leave charging station)
9: Request Right-of-Way (signal to other robots)
10: Emergency Stop (immediate halt, safety mechanism)
```

**Action Constraints**:
- Cannot pickup if battery < 30% and package is heavy
- Cannot move if battery = 0% (episode failure)
- Cannot charge if not at charging station
- Wait action still consumes 0.5% battery (idle power)

## 💰 ENHANCED REWARD STRUCTURE

```python
def calculate_reward(state, action, next_state):
    reward = 0
    
    # === SAFETY PENALTIES (Highest Priority) ===
    if collision_with_human:
        reward -= 200  # CRITICAL safety violation
    if collision_with_forklift:
        reward -= 150  # Equipment damage + safety
    if entered_restricted_zone:
        reward -= 50   # Authorization violation
    if within_human_safety_zone(1.5m):
        reward -= 30   # Too close warning
    if collision_with_other_robot:
        reward -= 40   # Coordination failure
    
    # === BATTERY MANAGEMENT ===
    if battery < 20 and not moving_to_charger:
        reward -= 20   # Should be charging!
    if battery < 10:
        reward -= 50   # CRITICAL low battery
    if battery == 0:
        reward -= 300  # Mission failure
        terminate_episode = True
    if action == "Start_Charging" and battery < 30:
        reward += 5    # Good decision
    if started_charging_too_early (battery > 70%):
        reward -= 10   # Inefficient
    
    # === TASK COMPLETION REWARDS ===
    if successful_pickup:
        reward += 60
    if successful_delivery:
        reward += 150  # Main objective
    if completed_urgent_task_on_time:
        reward += 100  # Bonus for urgency
    if failed_urgent_deadline:
        reward -= 80   # Failed priority task
    
    # === EFFICIENCY REWARDS ===
    if moving_toward_goal and battery_sufficient:
        reward += 3    # Progress reward
    if taking_optimal_path:
        reward += 2    # Path efficiency
    if action == "Wait" and not necessary:
        reward -= 5    # Time wasting
    reward -= 1        # Time step penalty (encourage speed)
    
    # === OPERATIONAL COMPLIANCE ===
    if yielded_to_forklift:
        reward += 8    # Safety compliance
    if used_designated_corridors:
        reward += 2    # Following warehouse rules
    if avoided_congested_area_proactively:
        reward += 5    # Smart navigation
    if requested_right_of_way_appropriately:
        reward += 3    # Good coordination
    
    # === HANDLING SPECIFIC PACKAGE TYPES ===
    if carrying_fragile and moved_smoothly:
        reward += 4    # Careful handling
    if carrying_heavy and speed_reduced:
        reward += 2    # Safe heavy handling
    if carrying_fragile and used_high_traffic_route:
        reward -= 15   # Risky path choice
    
    return reward
```

## 🏭 ENHANCED ENVIRONMENT IMPLEMENTATION

```python
import gymnasium as gym
import numpy as np
from gymnasium import spaces
from enum import Enum

class PackageType(Enum):
    NONE = 0
    STANDARD = 1
    FRAGILE = 2
    HEAVY = 3
    URGENT = 4

class ZoneType(Enum):
    CORRIDOR = 0
    STORAGE = 1
    RESTRICTED = 2
    CHARGING = 3
    PACKING = 4
    SHIPPING = 5
    RECEIVING = 6

class WarehouseAMREnv(gym.Env):
    """
    Enhanced Warehouse AMR Environment with Real-World Constraints
    """
    
    def __init__(self, config):
        super().__init__()
        
        # Grid configuration
        self.grid_size = 20
        self.max_steps = 600
        
        # Battery system
        self.battery_max = 100
        self.battery_drain_move = 1
        self.battery_drain_heavy = 2
        self.battery_drain_idle = 0.5
        self.battery_charge_rate = 5
        self.battery_critical = 20
        
        # Define zones on grid
        self.zones = {
            'storage_a': [(2,2), (5,5)],      # Electronics
            'storage_b': [(2,8), (5,11)],     # Textiles
            'storage_c': [(2,14), (5,17)],    # Tools
            'receiving_1': [(0,0), (1,3)],    # Truck dock
            'receiving_2': [(0,17), (1,19)],  # Rail dock
            'packing_1': [(15,2), (17,5)],    # Standard
            'packing_2': [(15,8), (17,11)],   # Fragile
            'shipping_local': [(18,0), (19,4)],
            'shipping_express': [(18,7), (19,11)],
            'shipping_intl': [(18,14), (19,19)],
            'charging_main': [(10,0), (11,2)],
            'charging_emergency': [(10,17), (11,19)],
            'restricted_office': [(7,7), (9,9)],
            'restricted_break': [(12,7), (14,9)],
            'restricted_qc': [(7,14), (9,16)]
        }
        
        # Human behavior profiles
        self.human_configs = [
            {'role': 'picker', 'zones': ['storage_a', 'storage_b'], 'speed': 1},
            {'role': 'packer', 'zones': ['packing_1', 'packing_2'], 'speed': 1},
            {'role': 'shipper', 'zones': ['shipping_local', 'shipping_express'], 'speed': 1},
            {'role': 'receiver', 'zones': ['receiving_1', 'receiving_2'], 'speed': 1},
        ]
        
        # Task specifications (source -> destination pairs)
        self.task_library = [
            # Inbound tasks
            {'pickup': 'receiving_1', 'delivery': 'storage_a', 'type': PackageType.STANDARD},
            {'pickup': 'receiving_2', 'delivery': 'storage_b', 'type': PackageType.HEAVY},
            
            # Outbound tasks
            {'pickup': 'storage_a', 'delivery': 'packing_1', 'type': PackageType.STANDARD},
            {'pickup': 'storage_b', 'delivery': 'packing_2', 'type': PackageType.FRAGILE},
            {'pickup': 'packing_1', 'delivery': 'shipping_local', 'type': PackageType.STANDARD},
            {'pickup': 'packing_2', 'delivery': 'shipping_express', 'type': PackageType.FRAGILE},
            
            # Transfer tasks
            {'pickup': 'storage_a', 'delivery': 'storage_c', 'type': PackageType.STANDARD},
            {'pickup': 'storage_b', 'delivery': 'storage_a', 'type': PackageType.HEAVY},
            
            # Urgent tasks (with deadline)
            {'pickup': 'storage_c', 'delivery': 'shipping_express', 'type': PackageType.URGENT, 'deadline': 200},
        ]
        
        # Observation and action spaces
        self.observation_space = spaces.Box(
            low=0, high=1,
            shape=(self.grid_size, self.grid_size, 12),
            dtype=np.float32
        )
        
        self.action_space = spaces.Discrete(11)
        
        # State variables
        self.reset()
    
    def reset(self, seed=None, options=None):
        super().reset(seed=seed)
        
        # Robot state
        self.robot_pos = np.array([10, 10])
        self.battery = 100
        self.carrying = PackageType.NONE
        self.is_charging = False
        
        # Task state
        self.current_task = self._generate_new_task()
        self.task_stage = 'pickup'  # or 'delivery'
        self.steps = 0
        
        # Initialize humans (4-5 workers)
        self.humans = self._initialize_humans(n=4)
        
        # Initialize forklifts (1-2)
        self.forklifts = self._initialize_forklifts(n=1)
        
        # Initialize other robots (1-2)
        self.other_robots = self._initialize_other_robots(n=2)
        
        # Dynamic obstacles
        self.blocked_cells = []
        
        return self._get_observation(), {}
    
    def step(self, action):
        self.steps += 1
        reward = 0
        terminated = False
        truncated = False
        
        # 1. Execute robot action
        reward += self._execute_robot_action(action)
        
        # 2. Update battery
        battery_drain = self._calculate_battery_drain(action)
        self.battery = max(0, self.battery - battery_drain)
        
        # 3. Check battery critical states
        if self.battery == 0:
            reward -= 300
            terminated = True
        elif self.battery < 20 and not self._is_near_charger():
            reward -= 20
        
        # 4. Update humans (realistic movement)
        self._update_humans()
        
        # 5. Update forklifts (patrol routes)
        self._update_forklifts()
        
        # 6. Update other robots (scripted tasks)
        self._update_other_robots()
        
        # 7. Check for collisions and safety violations
        collision_penalty = self._check_collisions()
        reward += collision_penalty
        if collision_penalty < -100:
            terminated = True  # Critical safety violation
        
        # 8. Check zone authorization
        if self._in_restricted_zone():
            reward -= 50
        
        # 9. Check task completion
        task_reward = self._check_task_progress()
        reward += task_reward
        
        # 10. Check if task completed successfully
        if self.task_stage == 'completed':
            reward += 150
            self.current_task = self._generate_new_task()
            self.task_stage = 'pickup'
        
        # 11. Time step penalty
        reward -= 1
        
        # 12. Check truncation
        if self.steps >= self.max_steps:
            truncated = True
        
        observation = self._get_observation()
        info = {
            'battery': self.battery,
            'task_stage': self.task_stage,
            'collisions': collision_penalty < 0,
            'task_type': self.current_task['type'].name
        }
        
        return observation, reward, terminated, truncated, info
    
    def _generate_new_task(self):
        """Randomly select a task from library"""
        task = np.random.choice(self.task_library)
        # 30% chance to make it urgent
        if np.random.random() < 0.3:
            task['type'] = PackageType.URGENT
            task['deadline'] = self.steps + 200
        return task
    
    def _initialize_humans(self, n):
        """Initialize human workers with realistic behaviors"""
        humans = []
        for i in range(n):
            config = np.random.choice(self.human_configs)
            zone = np.random.choice(config['zones'])
            pos = self._random_position_in_zone(zone)
            
            humans.append({
                'id': i,
                'pos': pos,
                'role': config['role'],
                'preferred_zones': config['zones'],
                'speed': config['speed'],
                'state': 'working',  # or 'walking', 'chatting', 'break'
                'target': None,
                'idle_counter': 0
            })
        return humans
    
    def _update_humans(self):
        """Update human positions with realistic behavior"""
        shift_phase = self._get_shift_phase()
        
        for human in self.humans:
            # Determine behavior based on shift and random factors
            rand = np.random.random()
            
            if shift_phase == 'lunch':
                # Move toward break areas
                if rand < 0.7:
                    human['target'] = self._get_zone_center('restricted_break')
                    human['state'] = 'walking'
                else:
                    human['state'] = 'break'
                    human['idle_counter'] += 1
            else:
                # Normal work behavior
                if rand < 0.6:  # Purposeful movement
                    zone = np.random.choice(human['preferred_zones'])
                    human['target'] = self._get_zone_center(zone)
                    human['state'] = 'working'
                elif rand < 0.85:  # Continue current state
                    pass  # Keep current state
                else:  # Random walk or chat
                    if rand < 0.92:
                        human['state'] = 'walking'
                        human['target'] = self._random_nearby_position(human['pos'])
                    else:
                        human['state'] = 'chatting'
                        human['idle_counter'] = 5  # Stop for 5 steps
            
            # Execute movement
            if human['state'] == 'walking' and human['target'] is not None:
                if human['idle_counter'] > 0:
                    human['idle_counter'] -= 1
                else:
                    human['pos'] = self._move_toward(human['pos'], human['target'], human['speed'])
            elif human['state'] in ['chatting', 'break']:
                if human['idle_counter'] > 0:
                    human['idle_counter'] -= 1
                else:
                    human['state'] = 'working'
    
    def _get_shift_phase(self):
        """Determine current shift phase"""
        if 200 <= self.steps <= 250:
            return 'lunch'
        elif self.steps < 200:
            return 'morning'
        else:
            return 'afternoon'
    
    def _check_collisions(self):
        """Check for collisions with all entities"""
        penalty = 0
        
        # Check human collisions (exact position)
        for human in self.humans:
            if np.array_equal(self.robot_pos, human['pos']):
                penalty -= 200  # CRITICAL
            elif np.linalg.norm(self.robot_pos - human['pos']) < 1.5:
                penalty -= 30  # Safety zone violation
        
        # Check forklift collisions
        for forklift in self.forklifts:
            if np.array_equal(self.robot_pos, forklift['pos']):
                penalty -= 150
            elif np.linalg.norm(self.robot_pos - forklift['pos']) < 3:
                penalty -= 5  # In danger zone
        
        # Check other robot collisions
        for robot in self.other_robots:
            if np.array_equal(self.robot_pos, robot['pos']):
                penalty -= 40
        
        return penalty
    
    def _execute_robot_action(self, action):
        """Execute robot action and return immediate reward"""
        reward = 0
        
        # Movement actions (0-3)
        if action < 4:
            directions = [
                np.array([-1, 0]),  # North
                np.array([1, 0]),   # South
                np.array([0, 1]),   # East
                np.array([0, -1])   # West
            ]
            
            new_pos = self.robot_pos + directions[action]
            
            # Check bounds and obstacles
            if self._is_valid_position(new_pos):
                self.robot_pos = new_pos
                
                # Reward progress toward goal
                if self._moving_toward_goal(directions[action]):
                    reward += 3
            else:
                reward -= 10  # Tried to move into obstacle
        
        # Wait action (4)
        elif action == 4:
            # Check if waiting was necessary
            if not self._is_blocking_required():
                reward -= 5
        
        # Pickup action (5)
        elif action == 5:
            if self._at_pickup_location() and self.carrying == PackageType.NONE:
                self.carrying = self.current_task['type']
                self.task_stage = 'delivery'
                reward += 60
            else:
                reward -= 15  # Invalid pickup attempt
        
        # Drop action (6)
        elif action == 6:
            if self._at_delivery_location() and self.carrying != PackageType.NONE:
                self.carrying = PackageType.NONE
                self.task_stage = 'completed'
                reward += 150
            else:
                reward -= 15  # Invalid drop attempt
        
        # Start charging (7)
        elif action == 7:
            if self._at_charging_station() and not self.is_charging:
                self.is_charging = True
                reward += 5
            else:
                reward -= 10
        
        # Stop charging (8)
        elif action == 8:
            if self.is_charging:
                self.is_charging = False
                if self.battery < 50:
                    reward -= 20  # Stopped charging too early
            else:
                reward -= 5
        
        return reward
    
    def _get_observation(self):
        """Generate multi-channel observation tensor"""
        obs = np.zeros((self.grid_size, self.grid_size, 12), dtype=np.float32)
        
        # Channel 0: Robot position
        obs[self.robot_pos[0], self.robot_pos[1], 0] = 1.0
        
        # Channel 1: Battery level visualization
        obs[:, :, 1] = self.battery / 100.0
        
        # Channel 2: Current task path
        if self.task_stage == 'pickup':
            target_zone = self.current_task['pickup']
        else:
            target_zone = self.current_task['delivery']
        self._mark_zone(obs, target_zone, channel=2)
        
        # Channel 3: Humans
        for human in self.humans:
            x, y = human['pos']
            obs[x, y, 3] = 1.0
        
        # Channel 4: Forklifts with danger zones
        for forklift in self.forklifts:
            x, y = forklift['pos']
            obs[x, y, 4] = 1.0
            # Mark danger zone
            for dx in range(-3, 4):
                for dy in range(-3, 4):
                    nx, ny = x + dx, y + dy
                    if 0 <= nx < self.grid_size and 0 <= ny < self.grid_size:
                        obs[nx, ny, 4] = max(obs[nx, ny, 4], 0.3)
        
        # Channels 5-11: Other features...
        # (Implementation continues for other channels)
        
        return obs
    
    def render(self, mode='human'):
        """Visualize environment"""
        import matplotlib.pyplot as plt
        import matplotlib.patches as patches
        
        fig, ax = plt.subplots(figsize=(12, 12))

        ax.set_xlim(0, self.grid_size)

        robot_circle = plt.Circle(

            0.4, color=robot_color, alpha=0.8, edgecolor='black', linewidth=2
        )
        ax.add_patch(robot_circle)
        
        # Add info text
        info_text = f"Battery: {self.battery:.0f}%\n"

        info_text += f"Carrying: {self.carrying.name}\n"
        info_text += f"Step: {self.steps}"
        ax.text(0.5, self.grid_size + 1, info_text,
                fontsize=10, verticalalignment='top')
        
        plt.title("Warehouse AMR Environment")
        plt.show()

    # Additional helper methods...
    def _is_valid_position(self, pos):
        """Check if position is valid"""
        x, y = pos
        if not (0 <= x < self.grid_size and 0 <= y < self.grid_size):
            return False
        # Check if position is blocked
        if tuple(pos) in self.blocked_cells:
            return False
        return True
    
    def _calculate_battery_drain(self, action):
        """Calculate battery drain based on action"""
        if self.is_charging:
            return -self.battery_charge_rate  # Negative = charging
        elif action < 4:  # Movement
            if self.carrying == PackageType.HEAVY:
                return self.battery_drain_heavy
            else:
                return self.battery_drain_move
        else:  # Non-movement actions
            return self.battery_drain_idle
```
